# Security policy

Games are untrusted content: a QSP script or the HTML of a game must not be able to read or change
files outside the game's folder, reach the network on its own, or run code outside the WebView.

## Reporting a vulnerability

Please do not report security problems in public issues. Use
[private vulnerability reporting](../../security/advisories/new) on GitHub (the *Report a
vulnerability* button on the *Security* tab).

Include the app version and flavor (`foss` or `play`), the Android version and, if possible, a
minimal game or file that reproduces the problem.

## Supported versions

Fixes are released in the latest version of the app only.
